# SL UI Library 1.2.1

This patch makes the five supported source formats explicit across current discovery and integration surfaces: HTML, CSS, JavaScript, React and Next.js.

- Updated the README introduction, source-format table, complete-package instructions and version notes.
- Updated portable, Claude and Codex plugin descriptions, the Codex short description, marketplace listing and source-selection skill.
- Updated the integration guide, website help, social-sharing metadata and showcase captions.
- Incremented package, plugin and bundled catalog metadata to 1.2.1 so version-aware clients can discover the new descriptions.

The catalog remains 388 owner-reviewed components / 390 export variants, including the 91 additions from [1.2.0](v1.2.0.md). Component markup, styles, controllers, framework adapters and the source bundle are unchanged.

React and Next.js remain source-preserving client-widget adapters, not native React-state rewrites or meaningful widget SSR. Download the complete package and follow its framework instructions. No personal plugin installation, public update channel, registry package, license or repository visibility change is part of this patch.
