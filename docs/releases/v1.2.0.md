# SL UI Library 1.2.0

91 owner-approved additions extend the existing 297 components to 388 entries / 390 export variants. Rejected local experiments are not included.

## Five source formats

HTML, CSS and JavaScript remain unchanged as supported integration formats. Every variant also provides Component.jsx (React), NextClient.jsx (Next.js client boundary), the original-controller adapter, a shared-font lifecycle helper, a complete callback-owning example and framework instructions. Download the whole package; the entry files are not standalone.

These are source-preserving adapters, not a native JSX rewrite or meaningful widget SSR. Initial server output is a stable client-widget placeholder. Shadow DOM isolates source styles. Real application callbacks, data operations, accessibility integration and form ownership remain the application's responsibility. Explicit preview examples only change local demonstration state.

## Catalog additions

The exact additions are listed in [the reviewed source map](v1.2.0-approved-elements.json). Existing IDs and all ten categories are preserved. Public interface labels are English; Unicode user text remains literal. Frozen local Russian owner-review sources are retained separately from public exports.

## Verification

The dated release QA report records actual commands, environments, per-purpose coverage and limitations. Generation or a successful framework build alone does not prove every interaction. Publication is a separate owner-authorized gate.
